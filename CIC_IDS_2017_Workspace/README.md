# CIC-IDS-2017 Cascade System Workspace

This workspace contains the implementation of a Multi-Stage Cascade Intrusion Detection System built on the CIC-IDS-2017 dataset.

## Directory Structure

*   `data/`: Contains both `raw/` dataset chunks and `processed/` feature-engineered CSV files.
*   `src/`: The core source code for the project.
    *   `data_processing/`: Contains the highly optimized data parsing and feature engineering engine (`cic_data_processor_v2.py`).
    *   `models/`: Contains the neural network architectures, notably the advanced `phase2_ft_transformer_v2.py`.
    *   `training/`: Contains the state-of-the-art `scripts_v7` which implements the final Hybrid Ensemble architecture (FT-Transformer + Random Forest + KNN).
*   `models/`: The saved model weights (`.pt`) and scalers (`.pkl`) generated by the training scripts.
*   `docs/`: Detailed markdown reports, architecture explanations, and work session logs.
*   `notebooks/`: Jupyter Notebooks used for EDA and initial data exploration.
*   `archive/`: Legacy training scripts (V2, V3, V4, V5, V6) kept for historical reference and documentation purposes.

## How to Run

1.  Ensure you have downloaded the raw data to `data/raw/`.
2.  Run data preprocessing: `python src/data_processing/cic_data_processor_v2.py`
3.  Run Stage 2 training (V7): `python src/training/scripts_v7/phase2_train_v7_stage2_ensemble.py`
4.  Evaluate the full cascade system: `python src/training/scripts_v7/evaluate_cascade_system_v7.py`
