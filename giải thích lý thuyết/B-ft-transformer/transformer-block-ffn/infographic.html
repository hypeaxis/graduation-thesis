✦ Transformer Block: họp nhóm → tự tiêu hoá ✦

Bọc Attention bằng FFN + đường tắt + chuẩn hoá → xếp chồng L tầng thành mạng sâu
KHỐI ATTENTION (Pre-LN)
T' = T + MHSA( LayerNorm(T) )
KHỐI FFN (Pre-LN)
T'' = T' + FFN( LayerNorm(T') )

🧠 FFN (phi tuyến)

GELU(zW₁+b₁)W₂+b₂, nở lên d_ff=4d rồi thu lại. Mỗi token tự "nghiền" ở phòng rộng gấp 4.

🔗 Residual (đường tắt)

T + …: cộng thêm, không thay thế. Gradient chảy thẳng về tầng dưới → chống vanishing gradient.

📏 LayerNorm

Chuẩn hoá mean 0, var 1 mỗi token → số không phình/teo qua từng tầng → ổn định.

Token→ MHSA (họp nhóm)→ FFN (tự tiêu hoá)→ × L tầng→ CLS → softmax
💡 Ý nghĩa: residual như bản nháp gốc luôn được giữ — mỗi tầng chỉ ghi chú bổ sung, lỡ ghi bậy vẫn lần về được. Cấu hình đề tài (V8.5): d=128, h=8, L=4, d_ff=512. Tầng thấp học quan hệ tổng quát → nền cho Layer Freezing khi thích nghi miền.
Đường tắt + chuẩn hoá = bí quyết huấn luyện mạng sâu!
